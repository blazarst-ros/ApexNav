# Lite-ApexNav 双机 MultiAgentSim 操作指南

本指南仅使用 Lite-ApexNav 的 YOLOE（12184）与 CLIPITM（12182）。不要启动
GroundingDINO、YOLOv7、SAM、BLIP2、真实世界桥接节点或第二个 planner；它们不是此
双机仿真路径的一部分，并可能覆盖话题或引入不受支持的模型请求。

## 0. 一次性构建与 Habitat-Lab 补丁

在未激活 Lite 环境的终端执行：

```bash
cd /home/blazarst/ApexNav
conda deactivate
unset LD_LIBRARY_PATH
catkin_make -DPYTHON_EXECUTABLE=/usr/bin/python3
bash scripts/setup_lite_multiagent_habitat.sh
```

`setup_lite_multiagent_habitat.sh` 只接受 Habitat-Lab v0.3.1 基线提交
`142616776544f918c19e7f0392b65cc8cc69fa13`。首次在干净 checkout 上应用补丁；再次
执行会报告“already applied”，不会重复修改。若它提示基线或本地改动错误，请按报错给出
的 `git -C ... checkout --detach ...` 或 `git -C ... status --short` 命令处理，切勿清理
仍需保留的本地改动。

每个终端都需要 ROS master（可单独开一个终端）：

```bash
source /opt/ros/noetic/setup.bash
roscore
```

## 1. 两个 Lite VLM 服务

以下命令各在独立终端运行；不下载模型，权重和 CLIP 缓存均来自
`/media/blazarst/Getea/Lite-ApexNav/model-cache`。

```bash
cd /home/blazarst/ApexNav
bash scripts/run-lite-multiagent.sh -m vlm.itm.clipitm --port 12182
```

```bash
cd /home/blazarst/ApexNav
bash scripts/run-lite-multiagent.sh -m vlm.detector.yoloe --port 12184
```

两个服务启动后，检查健康端点：

```bash
curl --fail http://127.0.0.1:12182/healthz
curl --fail http://127.0.0.1:12184/healthz
```

期望各返回 `{"status":"ok"}`。还可用 `rosnode list`、`rostopic list` 和
`rosrun rqt_graph rqt_graph` 检查 ROS 拓扑。

## 2. 一个共享地图 planner

只启动一个 C++ planner。它在同一进程内按 agent_0、agent_1 顺序规划，并让两台 agent
共享 SDF/Object/ValueMap；不要启动两份 `exploration.launch`。

```bash
cd /home/blazarst/ApexNav
source /opt/ros/noetic/setup.bash
source devel/setup.bash
roslaunch exploration_manager exploration.launch
```


## 3. 自动双机评测（三个数据集）

另开终端，任选一个数据集：

```bash
cd /home/blazarst/ApexNav
bash scripts/run-lite-multiagent.sh habitat_evaluation.py --dataset hm3dv1 test_epi_num=1
bash scripts/run-lite-multiagent.sh habitat_evaluation.py --dataset hm3dv2 test_epi_num=1
bash scripts/run-lite-multiagent.sh habitat_evaluation.py --dataset mp3d test_epi_num=1
```



## 4. 手动双机控制

planner 和两个 VLM 服务保持运行后，启动：

```bash
cd /home/blazarst/ApexNav
bash scripts/run-lite-multiagent.sh habitat_manual_control_multiagent.py --dataset hm3dv2
```

该入口仍按照其既有双机键盘控制与 ROS 话题逻辑执行；不要为两台 agent 分别启动 planner。


source /opt/ros/noetic/setup.bash
cd ~/ApexNav
source ./devel/setup.bash
roslaunch exploration_manager rviz_traj.launch
