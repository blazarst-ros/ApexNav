四、静态逻辑差异分析结论（已定位的可疑问题）
------------------------------------------
详见：双机改造静态逻辑差异分析.txt。核心：

  1) false positive 判定路径差异（最重要）：
     组B/组C 的 C++（双机版 fsm）在"到达物体点云目标点 <0.20m"即发布
     /ros/reach_claim；Python 据此把"声称到达但 geodesic 距离不足"判为
     false positive 并覆盖 Habitat 原生 success。基座单机 C++ 无此机制。
     C++ REACH 判定不看真实 goal 距离 → 误检物体直接触发 false positive。
  2) 标签归一化缺失：habitat_evaluation_multiagent.py 不调用
     normalize_objectnav_label（两个单机脚本都调用）→ sofa/tv_monitor/plant
     类别的 YOLOE 提示词不同（组B/组C 用原始标签）。
  3) 感知节奏：组B 单 agent 分支 STOP 后不再感知；组A 每步感知。
  4) 历史数据量化：false positive 单机就有 23%（23/100），双机放大到
     74%（26/35）——双 agent 放大机制：跨 agent 置信度累积、cooperative
     终止、感知轮换。
